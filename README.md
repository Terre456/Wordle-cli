 
# Merci d'avoir installé le Wordle du Terminal

Pour commencer a utiliser le Wordle du Terminal,assurez vous d'avoir JAVA d'installé dans une version recente et de pouvoir executer des scripts bash sous votre distribution

pour lancer le jeu lancez le script d'installation install.sh depuis le repertoire install_package_wordle-1.1 avec la commande

```
    bash ./install.sh
``` 

le jeu est a present accessible depuis le menu DEMARRER

## vous pouvez aussi l'installer sur Termux (android)
depuis termux faites:<br>
<code>
git clone https://github.com/Terre456/Wordle-cli
</code><br>
puis <br>
<code>
bash Wordle-cli/install-termux.sh
</code>
